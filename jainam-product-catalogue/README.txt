FREE WEBSITE SETUP

This is a static website and needs no paid hosting.

Easiest option: GitHub Pages
1. Create a free GitHub account.
2. Create a new public repository, e.g. jainam-product-catalogue.
3. Upload index.html and the assets folder.
4. In repository Settings > Pages, select Deploy from branch, main, /root.
5. Save. GitHub will provide a free pages URL.

The site includes search, category filtering, product images, MRP/MOP and Call/WhatsApp enquiry buttons for Jainam Kaka (8128930780).
